## 🔗 Paste a link, get a preview

Send a link in chat and LinkPreview will automatically fetch and display a rich embed. Just like in Discord.

Supported sites include:

| | Site | Preview includes |
|---|---|---|
| 🌐 | **Most Websites** | Page title and description |
| 🖼️ | **Images** | Inline preview of the image itself |
| 🎬 | **YouTube** | Video title, channel name, and thumbnail |
| 🎵 | **Spotify** | Track title, artist name, and thumbnail |

> 🔒 **The site never sees your IP.** To fetch link previews, LinkPreview connects to an external Cloudflare server on your behalf.

## 📥 Getting started

### 🎮 Minecraft Client

1. Download **LinkPreview** and the [Fabric API](https://modrinth.com/mod/fabric-api).
2. Drop it in your `mods/` folder.
3. Boot up Minecraft.
4. Send a link in chat. That's it!

> ⚠️ Only download from [Modrinth](https://modrinth.com/mod/linkpreview). Don't trust random sites!
